## 📌 Introduzione e Obiettivo
Il progetto è stato creato a scopo didattico con l'obiettivo di esporre in modo chiaro, accessibile e strutturato l'argomento del nuoto in vasca e dei suoi quattro stili principali (Delfino, Dorso, Rana e Stile Libero).

## 🛠️ Strumenti Utilizzati
* **HTML5:** per la strutturazione logica e semantica dei contenuti.
* **CSS3:** per la formattazione grafica, il layout e lo stile visivo.
* **Visual Studio Code:** come editor di testo principale per la scrittura del codice.
* **GitHub & GitHub Pages:** per il controllo versione e l'hosting del sito online.

## 🗂️ Struttura dei File e Gerarchia
Il sito è strutturato in **5 pagine complessive** (la Home Page più 4 sottopagine dedicate) gestite da un unico foglio di stile centralizzato.

```text
Cartella "NASTASA"
├── index.html                  # Home Page principale del sito
├── styles.css                  # Foglio di stile CSS unico per l'intero progetto
│
├── Immagini/                   # Cartella contenente i media
│   ├── banner.jpeg             # Banner fisso superiore
│   ├── delfino.jpg
│   ├── dorso.jpg
│   ├── rana.jpg
│   └── stile-libero.jpg
│
└── pagine secondarie/          # Sottocartella per le sezioni degli stili
    ├── pag1.html               # Pagina dedicata al Delfino
    ├── pag2.html               # Pagina dedicata al Dorso
    ├── pag3.html               # Pagina dedicata alla Rana
    └── pag4.html               # Pagina dedicata allo Stile Libero
